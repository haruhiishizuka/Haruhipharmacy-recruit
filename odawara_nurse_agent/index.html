私たちの想い

小田原ナース・パートナーズ 代表

「給料が上がらない」「求人票と実際の職場が違った」「紹介会社の担当に急かされて、納得しないまま転職してしまった」――そんな経験はありませんか。実は、その背景には高額な紹介手数料の問題があります。病院が紹介会社に支払う費用が大きいほど、あなたの給与や待遇に回せるお金は減っていきます。私たちはまず、この構造を変えたいと考えました。

だから、AIを活用して紹介コストを大幅に抑える仕組みをつくりました。ただのAIではありません。小田原エリアの病院・施設の内部事情や職場の雰囲気まで把握した、地域特化型のAIです。求人票だけではわからない「実際のところ」を踏まえて、あなたの希望と本当に合う職場をご提案します。紹介コストが下がった分は、病院があなたの待遇改善に充てられる。それが私たちの目指す転職のかたちです。

転職は人生の大きな決断です。急かされる必要はありません。まずはAIに気軽に相談するところから始めてみてください。「あなたの待遇が、きちんと良くなる転職」を一緒に実現しましょう。

よくある質問

Q 本当に完全無料で利用できますか？

はい、看護師の方は完全無料でご利用いただけます。適性診断・施設提案・履歴書作成まで、すべて無料です。費用は採用する医療機関側が負担する仕組みのため、求職者の方に料金が発生することは一切ありません。

Q LINEのAI相談とは何ですか？

LINE公式アカウントに友だち追加していただくと、AIチャットボットが24時間いつでもあなたの転職をサポートします。適性診断であなたのタイプを分析し、小田原エリアの最新情報や希望条件に合った施設をご提案。さらに、履歴書・職務経歴書の作成までLINE上で完結できます。

Q LINEで履歴書も作れるんですか？

はい、LINE上で基本情報・資格・職歴を入力するだけで、AIが自己PRを自動生成し、履歴書・職務経歴書を作成できます。完成した書類はPDFでダウンロード可能です。適性診断の結果やあなたの経験をもとに、看護師転職に最適化された自己PRを提案します。

Q 入力した個人情報は安全ですか？

はい、ご安心ください。すべての通信はSSL/TLS暗号化で保護されています。入力いただいた個人情報はご本人の同意なく第三者に提供することは一切ありません。履歴書データもセキュアなサーバーで管理しています。

Q 小田原エリア以外の求人も紹介してもらえますか？

当サービスは小田原市を中心に、南足柄市・湯河原町・箱根町・大井町・開成町・松田町など、神奈川県西部エリアの求人を専門に取り扱っています。エリアを絞ることで、職場の雰囲気や人間関係などの内部情報まで把握した、より精度の高いご提案が可能です。

Q 今すぐ転職するつもりはないのですが、相談だけでもいいですか？

もちろんです。「いつか転職したい」「今の職場と他の求人を比較したい」という段階でもお気軽にご相談ください。LINEのAIに話しかけるだけなので、しつこい勧誘や電話連絡は一切ありません。情報収集としてお使いいただけます。

Q 職場に転職活動がバレることはありませんか？

ご安心ください。個人情報は厳重に管理しており、ご本人の同意なく現在の職場や第三者に情報を提供することは一切ありません。LINEでのやり取りもトーク画面のみで完結するため、周囲に気づかれる心配はありません。

Q 紹介手数料が安いと聞きましたが、サービスの質に影響はありませんか？

AIを活用して業務効率化を図ることで紹介コストを抑えています。サービスの質を下げているわけではありません。むしろ、紹介手数料が低い分、採用する病院側があなたの給与や待遇に予算を回せるため、より良い条件での転職が実現しやすくなります。

Q 有料職業紹介事業の許可を持っていますか？

はい、当社（株式会社はるひメディカルサービス）は厚生労働大臣の許可を受けた有料職業紹介事業者です（許可番号：23-ユ-302928）。法令に基づいた適正な職業紹介を行っておりますので、安心してご利用ください。
