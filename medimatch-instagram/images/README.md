# 画像ファイル一覧

このフォルダには以下の画像を配置してください。

## 必要な画像

### 1. consultant_medimatch.jpg
- **用途**: Heroセクション
- **推奨サイズ**: 800x600px 以上
- **内容**: MediMatchコンサルタントの写真または医療現場のイメージ
- **形式**: JPEG, PNG

### 2. consultant_profile.jpg
- **用途**: 信頼訴求セクション
- **推奨サイズ**: 400x400px 以上
- **内容**: コンサルタントのプロフィール写真
- **形式**: JPEG, PNG

### 3. counselor_photo.jpg
- **用途**: カウンセラー紹介セクション
- **推奨サイズ**: 400x500px 以上
- **内容**: カウンセラーの顔写真またはプロフィール写真
- **形式**: JPEG, PNG

## 画像の最適化について

- ファイルサイズは1MB以下に圧縮してください
- Web用に最適化（解像度72dpi推奨）
- JPEG品質は80-90%が推奨

## プレースホルダー画像

実際の画像が用意できるまで、以下のサービスでプレースホルダーを使用できます：
- https://placehold.co/
- https://via.placeholder.com/

例：
- `https://placehold.co/800x600/2B7BB9/FFFFFF?text=Consultant`
